# 明天穿什么

一个记录「对象有哪些衣服」的手机 App。

收录衣服的**名称 + 图片**，自动把每件衣服处理成统一的样子，形成一本整齐的服装相册。另附多人的身材数据档案。

> **不做**推荐、**不做**虚拟试衣（3D 人体）、不做社交、不接天气。

## 第一版的口径

产品的质量只取决于两件事：

1. **录入够不够快** —— 单件录入超过 20 秒，这个 App 就会被弃用；
2. **相册看起来够不够整齐** —— 整齐感八成来自一致性（统一比例、统一底色、统一留白），不是像素。

所以：拍照后自动抠图、自动排版、自动分类，但**结果先进「待确认」队列**，用户翻一遍改错再入库。静默入库会摧毁信任。
