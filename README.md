# 明天穿什么

一个记录「对象有哪些衣服」的手机 App。

收录衣服的**名称 + 图片**，自动把每件衣服处理成统一的样子，形成一本整齐的服装相册。另附多人的身材数据档案。

> **不做**推荐、**不做**虚拟试衣（3D 人体）、不做社交、不接天气。

## 第一版的口径

产品的质量只取决于两件事：

1. **录入够不够快** —— 单件录入超过 20 秒，这个 App 就会被弃用；
2. **相册看起来够不够整齐** —— 整齐感八成来自一致性（统一比例、统一底色、统一留白），不是像素。

所以：拍照后自动抠图、自动排版、自动分类、自动起名，但**结果先进「待确认」队列**，用户翻一遍改错再入库。静默入库会摧毁信任。

## 装到手机上

1. 先确认手机是哪种架构：**2020 年以后的基本都是 arm64**，装 `明天穿什么-0.4.0-arm64.apk`；不确定就装 `明天穿什么-0.4.0-universal.apk`（大一些但一定能装）；
2. 拷到手机（数据线、微信传文件、网盘都行），点开它，允许「安装未知来源应用」；
3. 装完桌面出现「明天穿什么」。

包是用 debug 证书签的（`app/android/app/build.gradle.kts` 里 `signingConfig = signingConfigs.getByName("debug")`），能直接装，但**不适合上应用商店**，也别用它覆盖安装以后从商店装的正式版。

安装包没进 git（`.gitignore` 里有 `*.apk`）。想重新生成，在 `app/` 下跑：

```powershell
flutter build apk --release --split-per-abi   # 按架构分开出，arm64 那份 71 MB
flutter build apk --release                    # 通用包，160 MB
```

跑法见 [`app/README.md`](app/README.md)。
